# Agent 协作指南

这个仓库是 Python LLM Agent 学习空间。所有在这里工作的 Agent 都应该保持改动小、可运行、便于学习。

## 工作原则

- 默认使用中文沟通和编写文档；代码标识符、库名、API 名称按原文保留。
- 优先写清晰示例，不要过早抽象。
- 不同框架实验保持隔离，除非明确需要共享代码。
- 某个示例验证出稳定模式后，再把可复用代码放到 `src/learn_llm/`。
- 复用或对比用的 Prompt 放到 `prompts/`。
- 学习笔记和设计决策放到 `docs/`。
- 不要提交真实 API Key、私有 Token 或生产数据。

## 目录职责

- `examples/langchain/`：LangChain 示例和专项实验。
- `examples/langgraph/`：LangGraph 示例和图工作流实验。
- `agents/`：Agent 设计说明、运行入口说明和实验索引。
- `src/learn_llm/`：多个示例共享的 Python 包代码。
- `tests/`：共享代码和关键示例行为的测试。
- `configs/`：安全配置模板。真实密钥放在本地环境变量中。
- `data/raw/`：原始样例数据，保持小规模且不含敏感信息。
- `data/processed/`：可重新生成的处理后数据。
- `docs/`：路线图、学习笔记、架构说明和取舍记录。

## 编码约定

- 默认使用 Python 3.11+，除非某个框架有特殊要求。
- 可复用代码优先补类型标注。
- Demo 脚本应能通过 `python path/to/file.py` 直接运行。
- 引入外部依赖时，要在环境文件或依赖文件中明确记录。
- 当行为被共享、有状态或容易回归时，补充聚焦的测试。

## 文档要求

新增示例时，说明：

- 示例演示什么。
- 如何运行。
- 需要哪些环境变量。
- 预期行为或样例输出。

新增 Agent 设计时，说明：

- Agent 目标。
- 可使用的工具。
- 维护的状态。
- 失败模式和防护边界。
- 下一步用于验证设计的实验。
