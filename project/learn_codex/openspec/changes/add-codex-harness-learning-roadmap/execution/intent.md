# Intent

原始意图锚。开工前由 `Master` 依据用户最初诉求固化，冻结、极少改；改动需用户确认。

## 原始诉求

- 基于当前 `learn_codex` 项目和已拉取的 Codex 源码，先拆解 Codex harness 的学习思路和路线全景。
- 以专家视角给小白拆解，要求系统且全面。
- 需要搭配一些可视化图片。
- 先拆解思路和步骤，不要求本轮完成所有源码专题深度分析。

## 关键约束

- 默认中文。
- 以 `repo/codex/` 的实际源码结构为事实来源。
- 输出应是项目文档资产，不只停留在聊天回复。
- Markdown 承载正文，但流程图/架构图/路线图必须用生成图片文件，放在 `image/` 子目录。
- 使用 OpenSpec 记录本轮路线全景交付。

## 明确的非目标

- 不修改上游 `repo/codex/` 源码。
- 不完成所有专题正文。
- 不引入真实 API Key、Token 或生产数据。
- 不把路线写成普通 Codex CLI 使用教程。

## 验收口径

- 新增一份面向小白的 Codex harness 学习路线全景文档。
- 文档包含系统分层、学习阶段、每阶段目标、源码入口、关键问题、产出和完成标准。
- 至少生成并引用一张路线全景图片。
- OpenSpec proposal/design/spec/tasks 存在并通过 strict 校验。
