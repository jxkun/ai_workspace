# Decisions

## D-001

- 决策内容：为 core 层文档规划创建独立 OpenSpec change `add-codex-core-module-doc-plan`。
- 原因：用户要求构建 OpenSpec 并推进完成态，且该任务不同于上一轮学习路线全景。
- 影响模块：M01, M02, M03, M04
- 生效时间：2026-09-07 14:07:00

## D-002

- 决策内容：core 文档规划采用“职责聚类覆盖模块”而不是“每个源码文件一篇文档”。
- 原因：`core/src` 文件较多，逐文件文档会割裂学习路径；职责聚类更适合让小白理解到可复设计的程度。
- 影响模块：M02, M03
- 生效时间：2026-09-07 14:08:00

## D-003

- 决策内容：core 层总览图使用 SVG 矢量图片。
- 原因：项目图片质量约束要求正式图示优先 SVG，避免像素感和线条粗糙。
- 影响模块：M04
- 生效时间：2026-09-07 14:08:00
