# Methodology Image Assets

本目录存放 `docs/methodology.md` 使用的方法论总览图片。

## Assets

- `codex-harness-study-methodology-v1.png`: 早期 PNG 版本，保留用于历史对照。
- `codex-harness-study-methodology-v2.svg`: 当前文档引用版本。使用矢量图形和系统字体，避免位图缩放造成的像素感、锯齿边缘和线条粗糙问题。

## Maintenance Notes

- 后续优先更新 SVG 源文件。
- 如果外部发布环境不支持 SVG，再从 v2 SVG 导出同名 PNG，不要删除旧 PNG。
